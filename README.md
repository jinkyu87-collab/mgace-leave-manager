# MGACE 연차관리 시스템

50인 규모 사업장을 위한 연차 관리 웹앱입니다. Node.js + Express + SQLite로 동작하며 별도 DB 서버 설치 없이 바로 실행할 수 있습니다.

## 주요 기능

- **개별 로그인**: 이름 + 생년월일(8자리) 로 로그인. 동명이인은 입사일이 빠른 순서로 `이름1`, `이름2` 형태로 자동 구분됩니다.
- **연차 현황**: 근로기준법 제60조 기준(입사 1년 미만 월 1일, 1년 이상 15일 + 2년마다 1일 가산, 최대 25일)으로 자동 계산.
- **연차 신청/승인**: 직원은 신청·취소, 관리자는 승인/반려 처리.
- **연차촉진제도 관리**: 사용기한 6개월 전부터 대상자 자동 표시 → 1차 촉구 발송 기록 → 근로자 응답(사용시기 지정) 기록 → 미응답시 2개월 전 2차(사용자 지정) 통보 기록까지 관리.
- **관리자 페이지**: 직원 등록/퇴사처리, 연차 승인, 연차촉진 대상자 관리.

## 설치 및 실행

```bash
npm install
cp .env.example .env   # 필요시 SESSION_SECRET 등 수정
node seed.js            # 최초 관리자 계정 생성 (.env 의 SEED_ADMIN_* 값 사용)
node server.js
```

브라우저에서 `http://localhost:3000` 접속 후, seed.js 로 만든 이름/생년월일로 로그인하면 관리자 화면(`/admin`)으로 이동합니다.

## 직원 등록

관리자 로그인 후 **직원관리** 메뉴에서 이름/생년월일/입사일을 입력해 직원을 등록합니다. 동명이인이 있으면 자동으로 `이름1`, `이름2`로 표시명이 부여됩니다(로그인 자체는 이름+생년월일 조합으로 구분되므로 문제없습니다).

## 연차 계산 기준

- 입사일 기준으로 매 1년마다 새로운 연차가 발생하고, 발생일로부터 1년간 사용 가능합니다(입사일 기준 방식). 회계연도 기준으로 변경하려면 `utils/leaveCalculator.js` 의 `currentLeaveYearStart` 로직을 조정하세요.

## 연차촉진 절차 (근로기준법 제61조)

1. **1차 촉구**: 사용기한 만료 6개월 전, 미사용 연차 일수를 서면(문자/메일 등) 통보 — "1차 촉구 발송" 버튼으로 기록
2. **근로자 응답**: 통보 후 10일 이내 근로자가 사용 시기를 지정 — "근로자 응답 기록" 버튼으로 지정 일자 기록
3. **2차 통보(사용자 지정)**: 근로자가 응답하지 않으면 사용기한 만료 2개월 전까지 회사가 사용 시기를 지정하여 서면 통보 — "2차 지정통보 발송" 버튼으로 기록

실제 서면 통보(문자, 메일, 사내 공지 등)는 시스템 밖에서 별도로 발송하셔야 하며, 이 시스템은 발송 여부와 기한을 추적/기록하는 용도입니다.

## 배포 참고

- SQLite 파일(`db/leave.db`)에 데이터가 저장되므로, 배포 시 해당 파일이 위치한 디스크가 영구 보존되는 환경(예: Railway, Render의 persistent disk, 또는 자체 서버)을 사용하세요. Vercel 같은 서버리스 환경은 파일시스템이 휘발성이라 적합하지 않습니다.
- `SESSION_SECRET`은 반드시 운영 환경에서 임의의 긴 문자열로 변경하세요.
